# Yooooooooo!

一个用实体悠悠球选择任意支点、摆荡并释放惯性来移动的 2D 物理平台原型。

## 当前阶段

第一阶段移动原型。当前只验证“投掷—固定—摆荡—释放”是否有趣，不包含战斗、成长、正式美术或完整关卡。

## 操作

- `A/D` 或左右方向键：地面水平移动；固定后分别驱动逆时针/顺时针环绕（没有普通跳跃）。
- 按住鼠标左键：朝鼠标方向 360° 瞄准、蓄力并进入子弹时间。
- 松开鼠标左键：按当前蓄力投掷实体悠悠球。
- 鼠标右键或 `E`：随时收回悠悠球/解除绳索。
- `R`：重置角色位置和速度；坠落到测试区下方也会自动重置。

## 核心机制

悠悠球以连续碰撞检测的实体刚体直线飞行，首次碰撞的实际接触点成为世界支点。`DistanceJoint2D` 只约束最大绳长，不清零角色速度；解除后完整保留释放瞬间的线速度。瞄准使用无限子弹时间，蓄力使用未缩放时间。

## 运行

1. 使用 Unity `2022.3.62f2c1` 打开仓库。
2. 打开 `Assets/Scenes/PhaseOnePrototype.unity`。
3. 进入 Play Mode。

若目标场景尚未生成，可执行菜单 `Yooooooooo > Build Phase One Prototype Scene`。场景构建只在编辑器内发生；运行时不会创建 UI。

## 已实现

- 物理角色水平移动、重力和无跳跃控制。
- 鼠标 360° 瞄准、未缩放时间蓄力、子弹时间。
- 可调速度的实体悠悠球、连续碰撞检测、超时安全回收。
- 任意普通 Collider2D 的精确碰撞点固定。
- 最大绳长约束、摆荡、立即收回和惯性保留。
- 地面、墙、天花板、平台、宽坑和高台组成的灰盒场景。
- 预置的方向/蓄力 UI、速度与绳索调试信息、Gizmo 之外的绳线显示。
- 集中在 `YoyoTuning` 资产内的核心参数。

## 已知问题

- 尚未完成真实 Play Mode 试玩验证；物理参数是首轮默认值，需要实际手感迭代。
- 悠悠球固定在动态刚体时仍以世界坐标为支点；第一阶段灰盒只有静态表面。
- 极短绳长、高速角落碰撞、绕支点超过 180° 等边界行为尚未系统验证。
- UI 的瞄准箭头位于屏幕中央，用于原型反馈，不会跟随角色屏幕位置。

## 结构

- `Assets/Scripts`：移动、瞄准/悠悠球状态、弹体、慢动作、调试和重置逻辑。
- `Assets/Editor/PhaseOneSceneBuilder.cs`：编辑期创建灰盒场景和预置 UI。
- `Assets/Settings/YoyoTuning.asset`：集中调参资产（场景生成后存在）。
- `Assets/Scenes/PhaseOnePrototype.unity`：第一阶段试玩场景（场景生成后存在）。
- `docs`：实现记录与未来方向。
