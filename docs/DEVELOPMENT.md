# 开发记录

## 当前开发阶段

当前为**第二阶段测试**。第一阶段的投掷、精确固定、定长约束、收回和惯性继承保持为对照基线；第二阶段只增加一个可完全关闭的有限角加速度实验。关闭实验后不施加任何额外环绕驱动力。

## 当前实现方案

角色与悠悠球均使用 Unity 2D 物理。职责拆为 `PlayerMovement`、`YoyoController`、`YoyoProjectile`、`BulletTimeController`、`PrototypeHUD`、`PrototypeReset` 和 `CameraFollow2D`。核心数值集中在 `YoyoTuning` ScriptableObject，避免散落 magic number。

场景和 UI 由 `PhaseOneSceneBuilder` 在编辑期生成并序列化到场景。运行时脚本只更新已有 UI 的数值、方向和显隐，不创建 Canvas、Text、Slider 或 Image。

## 重要技术决策

- 使用旧输入接口读取水平轴和鼠标，减少第一阶段输入配置资产的复杂度。
- 不提供跳跃或任何直接向上冲量。
- 水平控制使用 `MoveTowards` 只调整速度的 x 分量；y 速度与摆荡产生的惯性不会被覆盖。
- 悠悠球是带 `Rigidbody2D` 和 `CircleCollider2D` 的实体，使用 `Continuous` 碰撞检测；不是射线抓钩。
- 命中点直接取第一个 `ContactPoint2D.point`，不搜索、吸附或修正支点。
- 发射时忽略悠悠球与玩家自己的碰撞，避免从角色中心生成后立刻自碰撞。这是实体发射所需的碰撞配置，不是移动限制。
- 未命中时按未缩放时间执行安全回收，避免慢动作延长玩家感知的最大飞行时间。
- 第二阶段不再用 A/D 选择固定后的旋转方向。系统通过当前切向速度判断已有方向；低于阈值时不启动，不凭空指定顺/逆时针。

## 物理约束方案

固定时启用玩家身上的 `DistanceJoint2D`，`connectedBody = null`，以精确命中世界坐标作为 `connectedAnchor`。初始距离取固定瞬间玩家刚体中心到命中点的距离，并使用双向定长约束维持环绕半径。`enableCollision` 保持开启，使玩家在约束生效期间仍与静态世界碰撞。

固定和释放都不直接修改玩家速度。释放只禁用 Joint 并隐藏悠悠球，因此释放瞬间的线速度由 `Rigidbody2D` 自然保留。当前没有额外冲量或速度钳制。

## 子弹时间方案

开始瞄准时设置 `Time.timeScale`，同时将 `Time.fixedDeltaTime` 按相同比例缩放；结束瞄准时恢复两者。瞄准方向每帧从角色到鼠标世界坐标计算。蓄力和飞行超时均基于 `Time.unscaledTime`，因此不同时间倍率与帧率下的现实时间体验保持一致。

## 关键参数（首轮默认值）

- 地面速度：12；地面加速度：70；空中控制：0.65；重力倍率：3。
- 最小/最大投掷速度：12 / 36；蓄力时间：1.1 秒。
- 悠悠球视觉自转速度：1080 度/秒。
- 子弹时间倍率：0.2。
- 最大飞行时间：2.5 秒（未缩放时间）。
- 绳索连接双方碰撞：开启。由于支点连接到静态世界，必须开启才能让玩家在 Joint 生效期间继续与墙和平台碰撞。
- 第二阶段角加速度实验：开启（可在调参资产中一键关闭）。
- 角加速度：4 rad/s²；最大角速度：8 rad/s；最低切向速度：0.1 单位/秒。

角加速度按当前绳长换算为切向加速度 `a = αr`。接近上限的最后一个物理步会缩小实验驱动力，避免实验自身把角速度继续推过上限。重力、碰撞或换支点等外部物理结果不会被强行钳制或刹车。

这些数值尚未经过第二阶段 A/B 试玩，只是便于首轮验证的起点。

## 构建器修复记录

- 2026-09-16：首次在 Unity Editor 内执行场景构建时，`Arial.ttf` 在 Unity 2022.3 中已不再是有效内置字体，导致构建在 HUD 引用绑定前中断。已改用 `LegacyRuntime.ttf`，并让 `PrototypeHUD` 在引用不完整时禁用自身并输出一次明确错误，避免每帧刷 `NullReferenceException`。
- 2026-09-16：修复灰盒使用内置 UI Sprite 时通过 Transform 缩放造成的视觉/碰撞尺寸不一致。现在 SpriteRenderer 使用显式 `size`，Collider 使用完全相同的尺寸，避免悠悠球撞到看不见的大型碰撞区域。
- 2026-09-16：悠悠球原先以玩家 Transform 中心作为弹体中心，视觉上会出现在角色身体内部。现改为沿瞄准方向从玩家 Collider 外缘加悠悠球半径的位置生成；仍属于从角色位置发射，不增加吸附、距离限制或额外冲量。
- 2026-09-16：根据实际试玩反馈，曾将 `DistanceJoint2D.maxDistanceOnly` 从最大长度绳索改为双向定长约束，以强化完整环绕。
- 2026-09-16：修复空中无输入时仍把水平速度拉向 0 的逻辑。地面继续使用目标速度控制；空中只在有方向输入时施加水平力，不自动刹车、不钳制已有速度，以保留和积累环绕所需的切向惯性。同时将首轮地面速度/加速度/空中控制提高到 12/70/0.65。
- 2026-09-17：为悠悠球增加独立视觉子物体和高对比轴心标记；投掷及固定期间以可调速度持续自转，收回时停止。该自转纯属视觉反馈，不向玩家或支点施加额外力。
- 2026-09-17：根据试玩反馈加入可解释的悠悠球环绕驱动。固定期间 A/D 不再使用普通世界水平空中力，而是分别沿逆时针/顺时针切线施加连续力，使悠悠球主动带动玩家积累角速度。驱动力不修改径向分量、不直接设置速度，也不设置角速度上限；释放后完整继承当前线速度。
- 2026-09-17：曾尝试通过提高 Physics 2D 求解迭代、Rigidbody/Capsule 预扫及接触回调速度投影处理高速环绕穿墙，但实际试玩仍出现缓慢穿墙，并引入过多干预。按试玩反馈已完整回退这些碰撞补丁，恢复 Unity 默认 8/3 求解迭代；穿墙问题重新列为待验证问题，不预先叠加更多限制或位置修正。
- 2026-09-17：曾误判双向定长 Joint 为穿墙根因并临时恢复 `maxDistanceOnly = true`；确认直接原因是 `enableCollision = false` 后，按试玩反馈撤销该临时改动，恢复双向定长环绕。
- 2026-09-17：进一步确认“一进入悠悠球状态便无视所有静态墙体”的直接原因是 `DistanceJoint2D.enableCollision = false`。Joint 的 `connectedBody` 为 null 时另一端代表静态世界，关闭连接双方碰撞会影响玩家与静态环境的接触。现将该参数默认值和调参资产都改为开启。
- 2026-09-17：进入第二阶段测试。移除固定后由 A/D 直接选择顺/逆时针的驱动方式，改为可独立关闭的角加速度实验。旋转方向只取自当前切向速度；低于阈值不启动；实验驱动受最大角速度约束。HUD 增加实验开关、切向速度、旋转方向和角速度信息。
