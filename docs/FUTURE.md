# 未来方向

本文件只记录方向，不代表自动进入实现。

## 待验证

- 第二阶段有限角加速度相对第一阶段基线是否增加操作空间，还是只会无脑放大机动性。
- 不同角加速度、最大角速度和最低切向速度阈值的 A/B 手感。
- 不同重力、移动加速度、投掷速度和绳索阻尼对学习曲线的影响。
- 极短/极长绳长、角落命中、高速换支点和超过 180° 绕点是否稳定且有趣。
- 爬墙、连续短挂、反向甩动、碰撞加速等行为是否扩展解空间。
- 动态平台上的支点是否应该跟随平台，以及如何保持规则可解释。
- 是否需要更贴近角色的瞄准方向反馈。

## 想法

- 围绕不同高度、天花板和狭窄通道设计的教学灰盒。
- 不在教程明说、但由基础规则自然产生的高级摆荡路线。
- 悠悠球飞行轨迹、命中点和绳索张力的更清晰视觉反馈。
- 命中、绳索绷紧、释放的轻量音效方向。
- 正式美术风格探索。
- 独立挑战关、计时/速通模式、排行榜与回放。

## 暂缓

- 敌人、伤害、战斗、技能树、商店、收集和剧情。
- 程序生成、多人联机、存档和关卡选择。
- 子弹时间资源、悠悠球冷却、体力系统。
- 预设钩点、不可固定材质、吸附点、防爬墙规则和用于防绕关的空气墙。

## 已确认

- 当前阶段保持任意普通碰撞表面与精确命中点固定。
- 收回后必须保留完整惯性。
- UI 必须预置在场景或 Prefab 中，运行时只更新状态。

## 放弃

- 第一阶段的普通跳跃、冲刺和瞬时射线抓钩方案。
